# InfoEduardo — Sabedoria de Gerações

Página de vendas do ebook de Eduardo Bem Estar, com layout adaptado para celular, imagens, amostras de páginas e botões de compra.

- Preço exibido: **R$ 19,99**.
- Checkout: https://pay.cakto.com.br/38j8s8t_1336861
- Produto: PDF com 110 receitas, 137 páginas e sete capítulos.

## Arquivos e edição

Site estático em HTML, CSS e JavaScript, sem instalação de dependências nem etapa de compilação.

- `index.html`: conteúdo da página.
- `styles.css`: apresentação e adaptação ao celular.
- `app.js`: interações, amostras, tamanho das letras e botões de compra.
- `site-config.js`: preço e endereço do checkout.
- `assets/`: imagens da página.

Abra `index.html` no navegador para visualizar. Para hospedar, use a raiz deste repositório como diretório de publicação. No GitHub Pages, selecione a branch `main` e a pasta `/ (root)` nas configurações do repositório. O envio dos arquivos não ativa a hospedagem automaticamente.

O PDF completo não está incluído neste repositório; as imagens internas são amostras. O checkout e a entrega do produto são gerenciados na plataforma de pagamento. Alterar o preço no site não altera o valor cobrado na plataforma.
